# JavaScript Concepts Learned (Counter Project)

This project tracks the progression of JavaScript concepts learned, as reflected in the comments and exercises in `counter.js`.

---

## Summary of Concepts Learned

1. **Basic Variable Usage**
   - Declaring variables with `const` and `let`.
   - Logging values to the console.

2. **Mathematical Operations**
   - Performing arithmetic with variables.
   - Using variables to store and calculate results.

3. **Reassigning and Incrementing Variables**
   - Changing variable values after initialization.
   - Incrementing and decrementing values step by step.

4. **DOM Manipulation**
   - Accessing HTML elements using `document.getElementById`.
   - Updating the content of HTML elements dynamically.

5. **Event Handling**
   - Adding buttons to HTML.
   - Using the `onclick` attribute to trigger JavaScript functions.
   - Responding to user interactions.

6. **Functions**
   - Defining reusable blocks of code with `function`.
   - Calling functions multiple times to avoid repetition.
   - Passing logic into functions for modular code.

7. **Practice with Functions**
   - Writing functions to perform calculations and log results.
   - Using functions for summing values and printing numbers.

8. **Connecting JavaScript to the UI**
   - Using JavaScript to update the UI in response to user actions.
   - Keeping the UI and data in sync.

9. **Understanding the Document Object Model (DOM)**
   - Recognizing how JavaScript interacts with HTML structure.

## Function Features Explained

```js
// Function declaration with parameters and return value
function add(a, b) {
  // Parameters: a, b
  // Function body: code that runs when the function is called
  const sum = a + b; // Local variable
  return sum; // Return statement
}

// Calling the function with arguments
const result = add(2, 3); // result is 5

// Features explained:
// - Functions can take parameters (inputs)
// - Functions can declare local variables
// - Functions can return a value
// - Functions can be called multiple times with different arguments
// - Functions help organize and reuse code
```
